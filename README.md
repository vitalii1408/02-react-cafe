# Sip Happens Café — Feedback App

Small React application that collects visitor feedback for a café and shows voting statistics.

## 🔗 Links

- **Live Demo:** [https://02-react-cafe-oh3ksbzrf-11-644c.vercel.app](https://02-react-cafe-oh3ksbzrf-11-644c.vercel.app)
- **Source code:** [github.com/vitalii1408/02-react-cafe](https://github.com/vitalii1408/02-react-cafe)

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- CSS Modules

## ✨ Features

- Vote buttons: Good / Neutral / Bad
- Statistics: total votes and positive feedback percentage
- Reset button that appears after the first vote
- Notification when there is no feedback yet

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/02-react-cafe.git
cd 02-react-cafe
npm install
npm run dev
```

Open the local address shown in the terminal (usually [http://localhost:5173](http://localhost:5173)).
